introduction: |
  JSON は API のレスポンス、設定ファイル、ログ出力などで最もよく使われるデータ形式です。マシンは JSON を簡単に解析できますが、ブラウザのコンソールや API クライアントが出力する JSON はたいてい 1 行に圧縮されており、人が読むのは非常に困難です。インターフェースの調査や設定の確認、ドキュメントの整理のたびに手動でインデントを整えるのは時間の無駄です。

  JSON フォーマッターは、圧縮された JSON をワンクリックでインデントの整った読みやすい形式に整形します。同時に構文チェックも行い、エラーがある場合は行番号と列番号付きで正確に教えてくれるので、問題箇所を素早く特定できます。容量を減らしたい場合は Minify モードで単一行に圧縮することも可能です。

  処理はすべてブラウザ内で完結し、データがサーバーに送信されることはありません。登録不要・無料で、機密情報を含むデータも安心して貼り付けられます。本ページでは主な機能と使い方を紹介します。
features:
  - title: JSON 整形・美化
    description: 圧縮された JSON を 2 スペースのインデントで読みやすい形式に変換。ネストしたオブジェクトや配列も自動で展開され、構造が一目でわかります。
  - title: JSON 圧縮（Minify）
    description: 余分な空白と改行をすべて取り除き、JSON を単一行のコンパクトな形式に圧縮。保存容量の削減やログ出力に便利です。
  - title: JSON 構文チェック
    description: 入力の構文を厳密に検証し、エラーがあれば行番号と列番号付きで通知。カンマ不足や引用符の不一致なども正確に検出します。
  - title: 大規模 JSON の処理
    description: 1 回の入力で最大 10MB まで対応。ブラウザ内で処理するため、大きなファイルでも高速に整形・検証できます。
guide:
  - step: 1
    title: JSON を貼り付ける
    description: 入力欄に処理したい JSON を貼り付けます。「サンプルを読み込む」で実際の例を試すこともできます。
  - step: 2
    title: 整形か圧縮かを選ぶ
    description: 「整形」でインデントを整え、「圧縮」で単一行にまとめ、「検証」で構文の正しさを確認します。
  - step: 3
    title: 結果を確認してコピー
    description: 結果はリアルタイムで表示されます。「結果をコピー」でクリップボードにコピーし、コードやドキュメントに貼り付けられます。
examples:
  - title: 圧縮された JSON を整形
    input: |
      {"name":"tool","version":"1.0.0","features":["format","validate"]}
    output: |
      {
        "name": "tool",
        "version": "1.0.0",
        "features": [
          "format",
          "validate"
        ]
      }
  - title: 構文エラーを検出して修正
    input: |
      {"user":"alice","roles":["admin","editor",]}
    output: |
      構文エラー: 1 行目 39 列目、閉じ括弧の前に余分なカンマがあります。
      "editor" の後のカンマを削除すると修正できます。
useCases:
  - API レスポンスの生データを確認し、フィールド構造を素早く把握する
  - フロントエンドとバックエンドの連携時にレスポンス例を見やすく整形する
  - 圧縮された設定ファイルを編集前に読みやすい形に整形する
  - データエクスポートの構造を分析して後続処理の準備をする
faqs:
  - question: JSON データはサーバーに送信されますか？
    answer: いいえ。整形・圧縮・検証はすべてブラウザ内で実行され、データがサーバーに送信されることはありません。機密情報を含むデータも安心して利用できます。
  - question: どのような JSON に対応していますか？
    answer: 標準の JSON 仕様（オブジェクト、配列、文字列、数値、真偽値、null）に対応しており、1 回の入力上限は 10MB です。
  - question: 日本語を含む JSON は扱えますか？
    answer: はい。日本語のテキストを含むフィールドも文字化けせず、そのまま整形・検証されます。
  - question: 整形と圧縮の違いは何ですか？
    answer: 整形はインデント付きの複数行で読みやすくする操作、圧縮は空白を削除して単一行にする操作です。用途に応じて切り替えられます。
