introduction: |
  URL には厳密な文字ルールがあります。使用できる文字は限られており、スペースや日本語、&、? などの特殊文字は、URL の中で安全に扱うためにパーセントエンコーディング（%エンコード）が必要です。この処理を間違えると、リンクやクエリパラメータ、API リクエストが静かに壊れ、原因の特定が難しくなります。

  URL エンコード/デコードツールは、テキストを URL 安全なパーセントエンコード形式に変換し、エンコード済みの文字列を可読なテキストに戻します。UTF-8 に正しく対応しているため、日本語や絵文字などの国際文字も文字化けせずに変換できます。リンクの作成、クエリ文字列の組み立て、ログに残ったエンコード文字列の確認まで、ワンクリックで完了します。

  処理はすべてブラウザ内で完結し、データがサーバーに送信されることはありません。登録不要・無料でご利用いただけます。本ページでは URL エンコードとデコードの使い方と、よくある質問を紹介します。
features:
  - title: URL エンコード
    description: テキストをパーセントエンコード形式に変換し、URL で許可されていない文字をエスケープ。リンク、クエリパラメータ、フォームデータに使えます。
  - title: URL デコード
    description: 「%20」や「%E4%BD%A0」などのエンコード文字列を元の可読テキストに戻し、URL が実際に何を含んでいるかを確認できます。
  - title: 特殊文字の処理
    description: スペース、&、?、#、日本語などエスケープが必要な文字を自動で処理し、URL の仕様に沿った結果を返します。
  - title: UTF-8 対応
    description: マルチバイト文字を UTF-8 で正しく処理し、日本語・絵文字などの国際文字もロスなくエンコード・デコードできます。
guide:
  - step: 1
    title: エンコードかデコードを選択
    description: 「エンコード」でテキストをパーセントエンコード形式に変換するか、「デコード」でエンコード文字列を可読文字に戻します。
  - step: 2
    title: テキストを入力
    description: 変換したいテキストや URL を貼り付けます。スペースや記号、国際文字は自動で処理されます。
  - step: 3
    title: 結果をコピー
    description: 変換結果がすぐに表示されるので、コード・リンク・API リクエストにコピーして使えます。
examples:
  - title: スペースと記号を含むテキストをエンコード
    input: |
      hello world & more
    output: |
      hello%20world%20%26%20more
  - title: UTF-8 の国際テキストをエンコード
    input: |
      こんにちは
    output: |
      %E3%81%93%E3%82%93%E3%81%AB%E3%81%A1%E3%81%AF
useCases:
  - リンクやリダイレクト URL のクエリパラメータを安全に組み立てる
  - ユーザー入力を URL やリダイレクト先に埋め込む前にエンコードする
  - ログやアクセス解析レポートに含まれるパーセントエンコード文字列をデコードする
  - Web 連携や API 呼び出しのためにフォームエンコード形式のペイロードを準備する
faqs:
  - question: URL エンコードとデコードの違いは何ですか？
    answer: エンコードはテキスト内の特殊文字をパーセントエンコード形式に変換して URL で安全に扱えるようにする操作、デコードはその逆にエンコード文字列を元のテキストへ戻す操作です。互いに逆の関係です。
  - question: 日本語を含む URL は扱えますか？
    answer: 扱えます。UTF-8 で処理するため、日本語や絵文字などの非 ASCII 文字も文字化けせず正しくエンコード・デコードされます。
  - question: URL エンコードは暗号化ですか？
    answer: いいえ。エンコードは文字のエスケープ表現であり、機密性はありません。誰でもデコードして元の内容を確認できるため、機密情報の保護には使わないでください。
  - question: データは安全ですか？
    answer: 安全です。エンコードとデコードはすべてブラウザ内で実行され、データがサーバーに送信されることはありません。
