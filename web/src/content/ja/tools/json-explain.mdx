introduction: |
  大きな JSON ペイロードは、ひと目で全体像を把握するのが難しいものです。API が数百のフィールドを複数階層にわたって返してくると、全体の構造、使われている型、データの深さ、機密情報が含まれていないかを確認するのはひと仕事で、新しい API と連携するたびに同じ作業を繰り返すことになります。

  JSON 構造分析ツールは、JSON ドキュメントを数秒で説明します。ルート型、トップレベルのフィールド数、総フィールド数、最大ネスト深度、フィールド型の分布、配列の中身の分析を報告します。さらに、パスワードやトークン、API キー、個人情報などのよくある機密フィールドをスキャンし、リスクレベル付きで警告するため、データ漏洩を未然に防ぐ手助けになります。処理はすべてブラウザ内で完結し、データがサーバーに送信されることはありません。

  本ページでは JSON 構造分析の使い方、ツールが検出できる内容、分析結果に関するよくある質問を紹介します。
features:
  - title: JSON 構造の分析
    description: 任意の JSON を貼り付けると、ルート型・トップレベルのフィールド数・再帰集計した総フィールド数・最大ネスト深度を即座に表示し、データの全体像をひと目で把握できます。
  - title: フィールド型の統計
    description: オブジェクト、配列、文字列、数値、真偽値、null など、ドキュメント全体の型の分布を表示し、配列の要素型も個別に集計します。
  - title: 機密フィールドの検出
    description: パスワード、トークン、API キー、カード番号、ID、連絡先などのよくある機密フィールドを自動スキャンし、高リスク・要注意のレベルで警告します。
  - title: プライバシーに配慮したローカル処理
    description: すべての分析はブラウザ内で実行されるため、機密情報を含む JSON でも安心してセキュリティチェックできます。
guide:
  - step: 1
    title: JSON を貼り付ける
    description: 入力欄に分析したい JSON を貼り付けます。ネストオブジェクト・配列・機密フィールドを含むサンプルも読み込めます。
  - step: 2
    title: 分析を開始
    description: 「分析」をクリックすると、構造サマリー・型の分布・セキュリティヒントが表示されます。不正な JSON はエラーの行番号と列番号を正確に通知します。
  - step: 3
    title: サマリーをコピー
    description: 「結果をコピー」で分析サマリーをクリップボードにコピーし、レポートやドキュメントに利用できます。
examples:
  - title: ネストした JSON ドキュメントを分析
    input: |
      {"user":{"id":1,"name":"alice","roles":["admin","editor"]},"items":[1,2,3]}
    output: |
      ルート型: object
      トップレベルフィールド数: 2
      総フィールド数: 8
      最大深度: 3
      型の分布: object x1, array x2, string x1, number x3
  - title: 機密フィールドを検出
    input: |
      {"username":"alice","password":"secret123","token":"eyJhbGciOiJIUzI1NiJ9"}
    output: |
      ⚠ 高リスク: password（パス: /password）
      ⚠ 高リスク: token（パス: /token）
useCases:
  - クライアントコードを書く前に、新しい API レスポンスの構造を把握する
  - 誤って公開されたシークレットや個人データが JSON ファイルにないか監査する
  - パーサーやバリデーターを作る前にペイロードの複雑さを評価する
  - 大きな JSON サンプルを要約してデータ契約をドキュメント化する
faqs:
  - question: JSON 構造分析ツールは無料ですか？
    answer: 完全に無料で、登録不要、利用回数の制限もありません。すべてブラウザ内で動作します。
  - question: JSON はサーバーに送信されますか？
    answer: いいえ。構造分析はブラウザ内で実行され、データがサーバーに送信されることはありません。機密情報を含む JSON も安心して分析できます。
  - question: 最大ネスト深度はどう計算されますか？
    answer: ルートノードを第 1 階層とし、深くなるたびに 1 加算します。例えば {"a":{"b":1}} の最大深度は 3 です。
  - question: どのような機密フィールドを検出しますか？
    answer: password、secret、token、apiKey、authorization、クレジットカード番号、ID、電話番号、メール、生年月日、住所などのよくあるフィールドを、高リスク・要注意のレベルで検出します。
