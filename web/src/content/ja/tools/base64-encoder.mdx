introduction: |
  Base64 は、メール添付、Data URL、JSON Web Token、API リクエストなど、さまざまな場面で使われる最も一般的なテキストエンコード方式のひとつです。文字列をエンコードして同僚に送る、サーバーから返された文字列をデコードするなど、開発者は日常的に Base64 を扱います。

  Base64 エンコード・デコードツールは、テキストと Base64 をワンクリックで相互変換できます。UTF-8 に対応しているため、日本語や絵文字などのマルチバイト文字も劣化なく往復できます。デコード時には形式の自動検証を行い、不正な Base64 が入力された場合は文字化けではなく明確なエラーメッセージを表示します。処理はすべてブラウザ内で完結し、データがサーバーに送信されることはありません。

  本ページでは、ツールの使い方、対応する文字の範囲、Base64 に関するよくある質問を紹介します。
features:
  - title: テキストを Base64 にエンコード
    description: 任意のテキストを入力するだけで Base64 文字列に変換。UTF-8 エンコーディングにより、日本語や絵文字などのマルチバイト文字も正しく処理されます。
  - title: Base64 をデコードしてテキストに戻す
    description: Base64 文字列を貼り付けてデコードモードに切り替えると、元のテキストを復元。デコード前に文字セットやパディングを自動検証します。
  - title: UTF-8 マルチバイト対応
    description: UTF-8 ベースのバイトエンコーディングにより、日本語、絵文字などの文字も劣化なく往復でき、結果が完全に一致します。
  - title: 結果のワンクリックコピー
    description: 変換結果はリアルタイムで表示され、「結果をコピー」でクリップボードにコピーできます。
guide:
  - step: 1
    title: エンコードかデコードかを選ぶ
    description: ツールバーで「エンコード → Base64」または「デコード → テキスト」を選択します。「サンプルを読み込む」でも試せます。
  - step: 2
    title: 内容を入力する
    description: 変換したいテキストまたは Base64 文字列を入力します。エンコードは日本語や絵文字に対応し、デコードは形式を自動検証します。
  - step: 3
    title: 変換してコピー
    description: 「エンコード/デコード」で結果をリアルタイムに取得し、「結果をコピー」でコードやドキュメントに貼り付けられます。
examples:
  - title: テキストを Base64 にエンコード
    input: |
      Hello, World!
    output: |
      SGVsbG8sIFdvcmxkIQ==
  - title: 日本語を含む Base64 をデコード
    input: |
      5L2g5aW977yM5LiW55WM
    output: |
      你好，世界
useCases:
  - Data URL や JSON リクエストに埋め込むためテキストをエンコードする
  - JWT のセグメントや API が返すトークンの中身を確認するためデコードする
  - メール添付や認証ヘッダー用のテストデータを準備する
  - 他システムが生成した Base64 が正しいかを検証する
faqs:
  - question: Base64 は暗号化ですか？
    answer: いいえ。Base64 は可逆なエンコード方式であり、安全性はありません。機密情報の保護には暗号化アルゴリズムを使用してください。
  - question: 日本語や絵文字は扱えますか？
    answer: はい。UTF-8 ベースのバイトエンコーディングにより、日本語や絵文字などのマルチバイト文字も劣化なく往復できます。
  - question: データはサーバーに送信されますか？
    answer: いいえ。エンコード・デコード処理はすべてブラウザ内で行われ、データがサーバーに送信されることはありません。
  - question: エンコードはどのような場面で使いますか？
    answer: URL や JSON で特殊文字やバイナリを安全に扱う、認証ヘッダーを作成する、テキストプロトコルで画像などのバイナリを表現するなどの場面で使われます。
