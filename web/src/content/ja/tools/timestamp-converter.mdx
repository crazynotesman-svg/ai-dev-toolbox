introduction: |
  Unix timestamp はバックエンドのあらゆる場所で使われています。データベースの保存形式、API のレスポンス、ログの記録——どれも epoch 秒やミリ秒の数値でやり取りされます。しかし 1723456789 のような数字はそのままでは何時なのかまったくわかりません。デバッグやログ確認のたびに手動で換算するのは非効率です。

  タイムスタンプ変換ツールは、Unix timestamp と日時の変換をワンクリックで行います。タイムスタンプを入力すればローカルタイムの日時を表示し、日時を入力すれば timestamp に変換します。10 桁の秒と 13 桁のミリ秒を自動判定するため、API がどちらの単位を返してきたかを気にする必要はありません。

  処理はすべてブラウザ内で完結し、データがサーバーに送信されることはありません。登録不要・無料です。本ページでは時刻変換の使い方、秒とミリ秒の違い、タイムゾーンについてのよくある質問を紹介します。
features:
  - title: Unix timestamp を日時に変換
    description: epoch の数値を貼り付けると、ローカルタイムの日時をすぐに表示。手計算や別ツールが不要です。
  - title: 日時を timestamp に変換
    description: 日時を入力すると対応する Unix timestamp を返します。秒・ミリ秒の両単位に対応し、コードや API パラメータにそのまま使えます。
  - title: 秒・ミリ秒の自動判定
    description: 10 桁の秒単位と 13 桁のミリ秒単位を自動的に見分けるため、API がどちらの単位を返してきても迷いません。
  - title: 時刻の形式表示
    description: 変換結果を複数の形式で表示し、コード・ログ・ドキュメントにコピーしやすい形で提供します。
guide:
  - step: 1
    title: タイムスタンプか日時を入力
    description: 入力欄に Unix timestamp を貼り付けるか、日時ピッカーで変換したい日時を指定します。
  - step: 2
    title: 変換方向を選択
    description: 「タイムスタンプ→日時」または「日時→タイムスタンプ」を選ぶと、入力に応じた変換結果が表示されます。
  - step: 3
    title: 結果を確認
    description: 変換結果はリアルタイムで表示されます。コピーしてコードのデバッグやログの確認、API パラメータの作成に使えます。
examples:
  - title: 秒単位のタイムスタンプを変換
    input: |
      1723456789
    output: |
      ローカル時刻: 2024-08-12 14:39:49（お使いのタイムゾーンで表示）
  - title: ミリ秒単位のタイムスタンプを変換
    input: |
      1723456789123
    output: |
      ローカル時刻: 2024-08-12 14:39:49.123（お使いのタイムゾーンで表示）
useCases:
  - epoch 時刻を返す API レスポンスをデバッグし、読みやすい日時をすばやく確認する
  - Unix timestamp に基づいてトークンの有効期限や署名付き URL の期限チェックを実装する
  - データベースの epoch 保存形式を読みやすいログの時刻に変換する
  - テストデータの作成や署名付きリクエストに使う現在のタイムスタンプを生成する
faqs:
  - question: Unix timestamp とは何ですか？
    answer: Unix timestamp（UNIX 時刻）は、1970 年 1 月 1 日 00:00:00 UTC からの経過秒数（またはミリ秒数）で、コンピューターシステムで広く使われる時刻の表現です。
  - question: 秒とミリ秒の違いは何ですか？
    answer: 秒単位のタイムスタンプは 10 桁で、Unix 紀元からの経過秒数を表します。ミリ秒単位は 13 桁で、ミリ秒まで含みます。このツールは両方を自動判定して処理します。
  - question: 変換結果はどのタイムゾーンで表示されますか？
    answer: お使いのローカルタイムゾーンで表示されます。環境で期待する時刻と一致する結果をすぐに確認できます。
  - question: データはサーバーに送信されますか？
    answer: いいえ。変換はすべてブラウザ内で実行され、データがサーバーに送信されることはありません。機密性の高い時刻データも安心して扱えます。
