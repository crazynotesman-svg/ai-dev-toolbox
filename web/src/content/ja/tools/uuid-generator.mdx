introduction: |
  UUID（Universally Unique Identifier）は、分散システムで衝突の少ない ID を生成する標準的な方法です。データベースの主キー、リクエストの追跡、リソースの命名、テストデータの作成など、新しい UUID をすぐに、そして毎回確実にユニークな値で用意したい場面は多くあります。

  UUID ジェネレーターは、プロジェクトが求める形式でバージョン 4 の UUID をその場で生成します。1 個の生成も、まとめての一括生成も可能で、結果はワンクリックでコピー、大文字・小文字も切り替えられます。処理はすべてブラウザ内で完結し、アップロードも登録も回数制限もありません。

  本ページでは UUID の生成方法、UUID v4 のユニーク性の仕組み、UUID の形式と用途に関するよくある質問を紹介します。なお、UUID はランダムな識別子として使うもので、パスワードや暗号鍵などのセキュリティ資格情報には使用しないでください。
features:
  - title: UUID v4 の生成
    description: 乱数ベースのバージョン 4 UUID を標準の 8-4-4-4-12 形式で生成。毎回まったく新しい値が生成されます。
  - title: 一括生成
    description: テストフィクスチャ、シードデータ、リソースの一括作成などに使えるよう、複数の UUID を一度に生成し、まとめてコピーできます。
  - title: 大文字・小文字の切り替え
    description: プロジェクトのコーディング規約やデータベースの保存形式に合わせて、大文字・小文字の出力を切り替えられます。
  - title: ワンクリックコピー
    description: 単一の UUID も一括の結果も、手動で選択することなくクリップボードに即コピーできます。
guide:
  - step: 1
    title: オプションを設定
    description: 生成する UUID の個数と、小文字・大文字のどちらで出力するかを選択します。
  - step: 2
    title: 生成
    description: 「生成」をクリックすると UUID が作成されます。生成のたびに完全に新しいランダムな値が作られます。
  - step: 3
    title: 結果をコピー
    description: 「コピー」で単一の UUID または一括の結果をクリップボードに入れ、コード・データベース・ドキュメントに貼り付けられます。

faqs:
  - question: UUID ジェネレーターは無料ですか？
    answer: 完全に無料で、登録不要、利用回数の制限もありません。どのモダンブラウザでも利用できます。
  - question: UUID v4 とは何ですか？
    answer: UUID v4 はランダムな値から生成されるバージョン 4 の汎用一意識別子です。128 ビットのランダム値により、通常の用途で衝突が起きる可能性は事実上ありません。
  - question: 生成される UUID は本当にユニークですか？
    answer: UUID v4 は 122 ビットのランダム部分を持つため、実際の衝突確率は無視できるほど小さく、多くのシステムの標準として使われています。
  - question: UUID をパスワードや鍵に使えますか？
    answer: おすすめできません。UUID はランダムな識別子であり、鍵に求められる機密性を備えていません。パスワードや API キー、暗号鍵などのセキュリティ資格情報には使用しないでください。
