introduction: |
  大型 JSON 数据很难一眼看清全貌。当接口返回成百上千个字段、嵌套多层结构时，要搞清楚整体结构、字段类型分布、数据嵌套深度，以及里面是否藏着敏感信息，往往需要花费不少精力，而且每接入一个新接口都要重复一遍。

  JSON 结构分析工具可以在几秒内解释一份 JSON 文档：报告根类型、顶层字段数、总字段数、最大嵌套深度、字段类型分布，以及数组内容的构成分析。它还会扫描常见的敏感字段，如密码、token、API 密钥和个人信息，并按风险等级提示，帮助你在数据泄漏发生前发现问题。整个过程在浏览器本地完成，数据不会上传到任何服务器。

  本页介绍 JSON 结构分析的使用方法、工具能检测的内容，以及关于分析结果的常见问题。
