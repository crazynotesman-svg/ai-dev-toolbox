introduction: |
  JSON 是前后端接口、配置文件与日志系统中最常见的数据格式。机器可以轻松解析 JSON，但浏览器控制台、接口响应和构建工具输出的 JSON 往往被压缩成一行，密密麻麻难以阅读。在排查接口数据、核对配置或整理文档时，手动调整缩进不仅浪费时间，还容易在复杂结构中看错层级。

  JSON 格式化工具可以在一键之间把压缩或杂乱的 JSON 变成缩进清晰、层级分明的可读结构，同时自动完成语法校验：如果 JSON 有错误，工具会提示具体的行号与列号，并给出错误类型说明，让你快速定位问题区域。对于需要压缩的场景，也提供了 Minify 模式，把 JSON 精简为单行，方便存储与传输。

  整个过程完全在浏览器本地运行，数据不会上传到任何服务器，无需注册、免费使用，适合直接粘贴包含敏感信息的业务数据。本页介绍工具的核心功能、使用方法与常见问题。
features:
  - title: JSON 格式化美化
    description: 一键将压缩或杂乱的 JSON 转换为两空格缩进的清晰结构，嵌套对象与数组自动展开成多行，字段关系一目了然。
  - title: JSON 压缩（Minify）
    description: 移除所有多余空白与换行，将 JSON 压缩为单行紧凑格式，适合减少存储体积、日志输出或接口传输时的数据量。
  - title: JSON 语法校验
    description: 对输入进行严格校验，非法 JSON 会提示错误类型，并精确定位到出错的行号与列号，快速修复缺失逗号、引号不匹配、多余尾逗号等常见问题。
  - title: 大 JSON 处理
    description: 支持单次 10MB 以内的 JSON 输入，足以覆盖绝大多数日常场景；配合本地处理，大文件也能快速完成格式化与校验。
guide:
  - step: 1
    title: 粘贴 JSON 数据
    description: 在输入框中粘贴需要处理的 JSON 文本，也可以点击"载入示例"快速体验工具效果。
  - step: 2
    title: 选择格式化或压缩
    description: 点击"格式化"美化缩进层级，点击"压缩"生成单行紧凑格式，点击"校验"检查语法是否合法。
  - step: 3
    title: 查看结果并复制
    description: 处理结果实时显示在输出区，点击"复制结果"一键复制到剪贴板，可直接粘贴到代码或文档中。
examples:
  - title: 格式化压缩的 JSON
    input: |
      {"name":"tool","version":"1.0.0","features":["format","validate"]}
    output: |
      {
        "name": "tool",
        "version": "1.0.0",
        "features": [
          "format",
          "validate"
        ]
      }
  - title: 校验并定位语法错误
    input: |
      {"user":"alice","roles":["admin","editor",]}
    output: |
      语法错误：第 1 行第 39 列，右括号前存在多余的逗号。
      删除 "editor" 后的逗号即可修复该 JSON。
useCases:
  - 调试接口返回的原始 JSON 数据，快速查看字段结构与层级关系
  - 前后端联调时美化响应示例，便于核对字段名与类型
  - 查看压缩的配置文件前先格式化，方便手工修改与审阅
  - 分析数据导出文件的结构，为后续数据处理做准备
faqs:
  - question: 使用这个工具时，我的 JSON 数据会上传到服务器吗？
    answer: 不会。格式化、压缩与校验全部在浏览器本地完成，数据不会离开你的设备，可以放心粘贴包含敏感信息的业务数据。
  - question: 工具支持哪些 JSON 内容？
    answer: 支持标准 JSON 规范的全部内容：对象、数组、字符串、数字、布尔值与 null，单次输入上限为 10MB。
  - question: 支持中文内容吗？
    answer: 支持。JSON 中的中文文本（如 name 字段）在格式化与校验中会原样保留，不会出现乱码。
  - question: 格式化和压缩有什么区别？
    answer: 格式化是把 JSON 变成带缩进的多行可读结构，方便人查看；压缩是去掉所有空白变成单行，适合存储与传输。两种模式可随时切换。
